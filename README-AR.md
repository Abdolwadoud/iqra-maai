# تطبيق اقرأ معي — مشروع Android

هذا مشروع Android Studio يحوّل موقع «مكتبة اقرأ معي» إلى تطبيق Android يستخدم WebView ويضم ملفات الموقع محلياً.

## بناء APK
1. فك ضغط الملف.
2. افتح مجلد `IqraMaaiAndroid` بواسطة Android Studio.
3. انتظر مزامنة Gradle وتنزيل أدوات Android المطلوبة.
4. من القائمة اختر **Build > Build APK(s)**.
5. بعد نجاح البناء اضغط **Locate** للحصول على ملف APK.

## تنبيهات
- هذا أرشيف مشروع جاهز للبناء وليس ملف APK مُجمّعاً.
- يلزم Android Studio/Android SDK واتصال بالإنترنت أول مرة لتنزيل أدوات البناء.
- إذا كانت إعدادات Supabase في `config.js` غير مكتملة، فلن تعمل الميزات التي تعتمد على قاعدة البيانات حتى تضيف بيانات مشروعك الصحيحة.
- راجع الروابط الخارجية وتسجيل الدخول وإدارة الكتب على جهاز حقيقي قبل نشر التطبيق.

## بناء APK عبر GitHub Actions (من دون تثبيت Android SDK على جهازك)
1. ارفع محتويات مجلد `IqraMaaiAndroid` إلى مستودع GitHub تملكه.
2. افتح تبويب **Actions** في المستودع.
3. شغّل **Build Iqra Maai APK** إن لم يبدأ تلقائياً.
4. بعد اكتمال البناء افتح تشغيل workflow ونزّل الملف من **Artifacts** باسم `iqra-maai-debug-apk`.
