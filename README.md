# مكتبة اقرأ معي — Iqra Maai Library

موقع عربي متجاوب (HTML/CSS/JavaScript) مع قاعدة بيانات Supabase. يتضمن الصفحة الرئيسية، فهرس الكتب، البحث والتصفية، صفحة تفاصيل الكتاب، ولوحة إدارة محمية للمكتبة.

## الملفات
- `index.html`: الصفحة الرئيسية.
- `books.html`: فهرس الكتب مع البحث والتصنيف والترتيب.
- `book.html`: تفاصيل الكتاب والكتب المشابهة.
- `admin.html`: لوحة المالك لإدارة الكتب والتصنيفات ومعلومات المكتبة.
- `app.js`, `style.css`: الوظائف والتصميم.
- `config.js`: إعدادات اتصال Supabase.
- `schema.sql`: الجداول وسياسات الأمان والتخزين.
- `seed-optional.sql`: بيانات كتب تجريبية اختيارية.
- `assets/`: الشعار والصور الموجودة في المشروع.

## مهم قبل التشغيل
النسخة المرفقة **ليست متصلة بقاعدة بيانات حقيقية بعد**. يجب إعداد Supabase أولًا. لا يمكن تسجيل دخول المالك أو حفظ الكتب قبل ذلك.

### 1. إعداد قاعدة البيانات
1. أنشئ مشروعًا في [Supabase](https://supabase.com/).
2. افتح SQL Editor ونفّذ `schema.sql` مرة واحدة في مشروع جديد. لا تعِد تشغيله على نفس المشروع دون إعداد ترحيل مناسب، لأن بعض الأوامر تنشئ جداول وسياسات ومشغلات.
3. اختياريًا، نفّذ `seed-optional.sql` لإضافة التصنيفات والكتب التجريبية. صور هذه الكتب مأخوذة من صور المشروع وليست بديلًا عن أغلفة أصلية عالية الجودة.
4. من إعدادات المشروع > API، انسخ Project URL ومفتاح `anon`/publishable إلى `config.js`. لا تضع مفتاح `service_role` أو أي مفتاح سري في الواجهة الأمامية.
5. من إعدادات المصادقة، عطّل التسجيل العام إذا كان الموقع مخصصًا لمالك واحد.

### 2. إنشاء حساب المالك
1. من Authentication > Users أنشئ المستخدم يدويًا بالبريد وكلمة مرور قوية.
2. انسخ UUID الخاص بالمستخدم.
3. نفّذ في SQL Editor، مع استبدال القيمة بالـ UUID الحقيقي:
   ```sql
   insert into public.profiles (id, role) values ('UUID-هنا', 'admin');
   ```
4. افتح `admin.html` وسجّل الدخول. لا توجد واجهة عامة لإنشاء صلاحية مدير.

### 3. تجربة الموقع محليًا
لا تفتح الملفات مباشرة عبر `file://` عند اختبار المصادقة. استخدم خادمًا محليًا أو استضافة ثابتة. إذا كان لديك Python على الكمبيوتر، شغّل من مجلد `iqra`:
```bash
python -m http.server 8000
```
ثم افتح `http://localhost:8000`.

### 4. النشر
يمكن نشر المجلد `iqra` على استضافة ثابتة مثل Netlify أو Cloudflare Pages أو GitHub Pages. بعد النشر، أضف عنوان الموقع إلى قائمة Redirect URLs في إعدادات Supabase Authentication. اختبر كل الوظائف على الموقع المنشور.

## الأمان والقيود
- يعتمد أمان البيانات على سياسات RLS في `schema.sql`، ويجب عدم تعطيلها.
- المفتاح المسموح به في الواجهة هو `anon`/publishable فقط؛ لا ترفع أسرارًا إلى GitHub.
- رفع أغلفة الكتب يمر عبر تخزين Supabase، مع تصغير الصورة في المتصفح.
- الاستفسار عبر واتساب ليس عملية شراء ولا يتضمن دفعًا إلكترونيًا أو إدارة طلبات.
- يجب مراجعة رقم الهاتف والعنوان وساعات العمل وحقوق استخدام الصور قبل النشر العام.
